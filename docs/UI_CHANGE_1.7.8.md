# Простой прогноз 1.7.8

Вкладка показывает число заказов на сегодня и возможный диапазон. Ниже — длительность слота, сколько часов из него курьер планирует работать, и кнопка импорта XLSX/JSON. Настройка сохраняется при изменении и применяется к следующим дням, пока её не изменят. После нового выбора сразу показывается свежий расчёт; неизменяемый утренний снимок сохраняется для внутренней проверки.

Сохранение не теряется при немедленном уходе с экрана. Старые планы с переносом работы через полночь не блокируют новую настройку общей длительности: указанная на сегодня сумма считается уже включающей ночной перенос. Старые фактические часы и исходные записи при этом не исправляются.

Фактические заказы, часы Яндекса и деньги каждого нового слота сохраняются отдельно. Для одной даты их суммы синхронизируются с историей прогноза; подтверждённое рабочее время за день записывается один раз. При повторном открытии/синхронизации суммы не удваиваются. План 8 ч внутри слота 14 ч не добавляет шесть часов простоя к рабочему времени и не превращается в подтверждённый факт.

Почасовой расчёт возможен лишь при наличии достаточной подтверждённой истории и реальных временных окон. Если пользователь указывает только две длительности, прогноз берёт проверенную дневную скорость работы, а не выдумывает время суток. Без пригодной истории экран просит импортировать отчёт.
