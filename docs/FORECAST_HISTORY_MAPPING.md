# Импорт истории: mapping и сомнения

Источник читается по явному выбору XLSX в Android, без сетевого обращения и без изменения оригинала. ZIP/XML reader ограничен8МБ входа/24МБ распаковки; формулы, внешние связи, DTD и макросы не исполняются. Выбираются три листа, остальные не импортируются.

| Лист/колонка | Приёмник | Правило |
|---|---|---|
| Дневные итоги A/E | дата/заказы | Подтверждённый дневной итог; формульные ячейки без факта пропускаются |
| Дневные итоги O | предполагаемые рабочие минуты | Десятичные часы×60, precision=total, workConfirmed=false до ручного подтверждения |
| Дневные итоги Q | часы Яндекса | Только явно числовое значение, отдельно от рабочего времени |
| Смены A/E/F/G | дневная сверка | Несколько строк одной даты суммируются; сравниваются с дневным итогом, не добавляются второй раз |
| Смены C/D, заметки | не подтверждают экспозицию | Границы могут быть реконструированы; шаблон не становится фактом |
| Заказы RAW A/C/D/L/M | evidence | Дата/видимое время/№заказа/принят/завершён. ID по дате+явному номеру; при отсутствии — сочетание исходных полей и occurrence. Одновременные разные заказы сохраняются |
| RAW суммы | не пишутся в деньги | Стоимость заказа не является ни чаевыми, ни гарантированной выплатой |
| Периодные снимки | не импортируются как дни | Накопительные итоги не складываются с дневными |
| Старые прогнозы | не становятся MORNING | Восстановленные timestamps не доказывают фиксацию до факта |
| Настройки владельца/финансовые правила | не применяются автоматически | Личный график/14,5часа не зашиты для других людей; старые определения дохода не меняют принятые формулы |

RAW-список может быть неполным. Совпадение количества с итогом не восстанавливает неизвестные границы доставки. availableNoOrderMin выводится только при полном доказательстве границ и подтверждённой готовности. Технический offline не вырезает выполняемый заказ; конфликт с личной паузой сохраняется и исключает день из обучения до уточнения.

Ручные рабочие окна, сумма без границ и подтверждённый знаменатель защищены от повторного импорта. Несогласованные заказы/учитываемые часы сохраняются как конфликт, не заменяются молча. Полная JSON-копия включает происхождение полей, ревизии, исходные evidence и сессии импорта. Финансовые entries не создаются; факт выплаты вводится в существующей форме слота.
