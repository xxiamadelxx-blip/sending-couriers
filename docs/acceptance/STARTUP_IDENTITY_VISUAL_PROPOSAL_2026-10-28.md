# Startup identity proposal · 28 October 2026

**Status: revised visual proposal, owner decision pending.** The current Android source still uses the previous green receipt launcher and Android 12 splash icon (`android/res/drawable/ic_launcher.xml`, `ic_receipt.xml`), old light launch background `#f4f7f3`, and native loading label in the earlier style. These precede the selected SHIFT CONTROL palette used on the main pages.

`design/review/startup-identity-concept.html` and its PNG are a **schematic visual proposal**, not an Android capture. The first three-panel draft was explicitly rejected by the owner: the receipt was too literal, and the extra “Рабочий ритм · Доход · Прогноз” tagline was redundant. The owner instructed us to keep the color scheme, use an abstract sign, and remove such redundant captions. This revised sheet shows two abstract marks A/B, each in dark and light themes. Inside the app views it contains only the app name.

Both signs use a graphite base, orange signal stripe, cream abstract geometry, and one gold element; neither depicts a receipt, ruble, courier, bike, route, or package. The loading background follows the already selected page colors `#10151a` (night) and `#eae7de` (day), with the app name only. Android's system splash shows only the mark, followed by the native short loading screen with the name. No finances, navigation, app ID, local data, permissions, or signing identity change.

If approved, implement the vector assets, Android themes and native loading view, then capture actual Android 35 startup screens in both themes and compare with the same app state. Owner verdict on those Android results is separate from approval of this concept. Until both, visual PASS is **PENDING**.
