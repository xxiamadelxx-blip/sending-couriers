# Startup identity proposal · 28 October 2026

**Status: revised implementation candidate, native visual review pending.** The baseline Android source used the previous green receipt launcher and Android 12 splash icon (`android/res/drawable/ic_launcher.xml`, `ic_receipt.xml`), old light launch background `#f4f7f3`, and native loading label in the earlier style. These preceded the selected SHIFT CONTROL palette used on the main pages.

`design/review/startup-identity-concept.html` and its PNG are **rejected schematic drafts**, not Android captures. The first three-panel draft was explicitly rejected by the owner: the receipt was too literal, and the extra “Рабочий ритм · Доход · Прогноз” tagline was redundant. The owner instructed us to keep the color scheme, use an abstract sign, and remove such redundant captions. The second sheet showed simple marks A/B; the owner rejected both. Neither rejected sign is shipped.

Following that direct direction, the implementation candidate uses a distinct four-part curved abstract glyph with negative space. The icon uses a graphite base, orange signal stripe, two cream parts and one gold part; it depicts no receipt, ruble, courier, bike, route, or package. The loading background follows the already selected page colors `#10151a` (night) and `#eae7de` (day), with the app name only. Android's system splash shows only the mark, followed by the native short loading screen with the name. The browser fallback has the same mark. No finances, navigation, app ID, local data, permissions, or signing identity change.

The production candidate changes the vector assets, Android themes, native loading view, and fallback browser splash. `qa/ui_audit_matrix.py` captures unaltered cold-start frames in both themes for Android 35 review. The owner's verdict on those Android results is **PENDING**; do not claim visual PASS before it.
