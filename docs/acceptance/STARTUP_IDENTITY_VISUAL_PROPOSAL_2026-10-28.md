# Startup identity proposal · 28 October 2026

**Status: visual proposal, owner decision pending.** The currently installed Android source still uses the previous green receipt launcher and Android 12 splash icon (`android/res/drawable/ic_launcher.xml`, `ic_receipt.xml`), old light launch background `#f4f7f3`, and native loading label in the earlier style. These precede the selected SHIFT CONTROL palette used on the main pages.

`design/review/startup-identity-concept.html` and its PNG are a **schematic visual proposal**, not an Android capture. The left panel combines the existing launcher mark and loading copy; the center and right panels show the proposed dark and light sequence. Android's system splash shows only the icon, followed by the native short loading screen with the name and subtitle.

The proposal retains the recognizable receipt and ruble symbol. The icon uses a graphite base, orange signal stripe, cream receipt outline, and gold ruble. The loading background follows the already selected page colors `#10151a` (night) and `#eae7de` (day), with uppercase name and a short three-part descriptor. No finances, navigation, app ID, local data, permissions, or signing identity change.

If approved, implement the vector assets, Android themes and native loading view, then capture actual Android 35 startup screens in both themes and compare with the same app state.
