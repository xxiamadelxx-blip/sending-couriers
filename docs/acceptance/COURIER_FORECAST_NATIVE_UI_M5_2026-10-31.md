# M5 — Подключение нативного прогноза к экранам «Сегодня» и «Неделя»

**Статус:** IN PROGRESS. Кодовый срез добавлен в отдельную ветку; сборка и Android-проверка этого среза ещё не выполнены.

**Основание:** M3 нативный движок PASS/CLOSED и M4 локальный видеоимпорт PASS/CLOSED. M4 остаётся закрытым по двум доступным MP4 (28 и 9 заказов), Android 35, запись фактов и сохранение после перезапуска: [приёмка M4](COURIER_FORECAST_VIDEO_IMPORT_M4_2026-10-29.md), [Actions #41145341250](https://github.com/xxiamadelxx-blip/sending-couriers/actions/runs/41145341250).

## Объём среза

- Android NativeBridge получает пакет до семи дат и вызывает AutonomousForecastStore.predict из локальной SQLite через уже используемую очередь зеркалирования.
- Экран текущего дня использует нативный результат для выбранных рабочих минут, если модель располагает подтверждённым количеством заказов и экспозицией WORK в том же часовом поясе.
- План на семь дней подставляет доступные нативные оценки в существующий расчёт риска и финансовых итогов. Подтверждённые факты завершённых дней остаются фактами.
- Если Android API отсутствует или нативная оценка недоступна, экран сохраняет текущий локальный JS/Worker-расчёт.
- Предсказания не публикуются в реестр, не оцениваются как факты и не меняют SQLite или JSON. Используется существующая подпись интерфейса; расположение и навигация не меняются.

## Инварианты

- В модель передаётся только запланированное рабочее время WORK, не полный слот и не часы Яндекса.
- Время/зона берётся из часового пояса профиля; при недостатке пригодных подтверждённых наблюдений отображается прежний локальный расчёт.
- Нативный запрос только читает факты и ограничен семью целями. Он не вызывает publish() или evaluate().
- M4 импорт заказа сам по себе не доказывает время ожидания или полную смену; неподтверждённая экспозиция не дополняется автоматически.

## Приёмка

| Критерий | Статус |
|---|---|
| Нативный результат доступен для прогноза текущего дня через Android bridge | Код подключён; Android сборка/запуск не проверены |
| Доступные нативные оценки участвуют в днях, диапазонах, рисках и финансовых итогах плана недели | Код подключён; регрессия не запущена |
| Завершённые подтверждённые дни остаются фактическими | Сохранён существующий путь displayWeekDay; тест не запускался |
