## Независимый Gauntlet

Независимый `/root/design_critic`, чтение исходников/собственные Node и browser проверки. Переданные проблемы исправлены и перепроверены: импорт ручных окон при входной rev99, будущий timezone, double-count источников, факт100+остаток4ч=112, незавершённый день, первый конфликтный импорт, overlap/overnight, размер backup, нулевой диапазон при малой истории, собственные zone/profileVersion исходного выпуска. Последняя проверка также закрыла malformed intervalForecasts: объект вместо массива, boolean и неверные границы отклоняются до записи; старые снимки без этого поля читаются. Итог: PASS проверенной логики M1–M5/M8. Это не подтверждение точности модели на реальной истории или M7/Android runtime.

## Ограничения модели

Диапазоны консервативные, по личной изменчивости, с широким fallback при малом n. Проценты вероятности выплаты не выдумываются. Суммирование дневных диапазонов сохраняет общий риск спроса; независимость дней не предполагается. Для окон используется общая интенсивность на рабочий час; детализация спроса по времени суток пока не доказана. Изменение факта улучшает только будущие расчёты, а не записанный исходный выпуск. Пропуски и неизвестный район не считаются сопоставимыми нулями.

Полная приёмка требует закрыть M6 live-network и M7, проверить запуск/обновление на Android, реальную калибровку и батарею. Пользователю не заявляется полный PASS всего ТЗ.
