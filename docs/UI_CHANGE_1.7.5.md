# Изменения интерфейса 1.7.5

Основание: последние прямые замечания владельца к двум экранам. Объём выпуска ограничен расположением данных и единым вводом факта.

1. Главная: три горизонтально пролистываемых страницы с явными пиктограммами и названиями **Темп → Доход → Премии**. Доход крупно показывает общий итог, выплачено, остаток, чаевые и отдельные бонусы; обе расчётные премии остаются отдельными суммами в рублях.
2. Прогноз: удалить дублирующую карточку «Сегодня · факт» и кнопку «Внести факт». Фактические часы работы задаются по выбранной дате в форме слота, открываемой через нижний «+». Часы и заказы каждого слота продолжают складываться; окна фактической работы сохраняются **один раз за день**. Не подменять их номинальным планом. Редактирование исторического факта/импорта остаётся в истории для исправлений.
3. Карточка оставшихся заказов называется «Прогноз до конца смены»: «Ещё N заказов», диапазон и оставшееся рабочее время. Численная модель не меняется.
4. «Условия оплаты» — восемь горизонтальных страниц: начало периода, ставка, темп оплаты, темп премии, минимум часов, критический темп, процент премии за темп, процент за 12 недель. Кнопка «Сохранить условия» одна для всей версии; неверное поле открывает нужную страницу. Ошибка локальной записи сохраняет черновик.

Двухнедельный календарь, схемы данных, финансовые формулы, модель прогноза, погода, нативный интерфейс хранилища, тема и подпись сохранены. Полный фоновый запуск модели в закрытом приложении, OCR и запуск APK на устройстве не подтверждаются этими правками.
